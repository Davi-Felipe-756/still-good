## Como dar commit
* git status (verifica o estado do git)
* git add . (adiciona todos os arquivo da raiz)
* git commit -m "TITULO-DO-COMMIT" (salva a atualização com o nome dela)
* git push (empurrar a atualizção)
* obs.: usar algum padrão de commit (commit patterns)
* git restore --staged . (cancela a atualização)
